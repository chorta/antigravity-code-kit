# 🚀 Anti-Gravity: Living Shell Starter Kit

Welcome to the official developer starter kit for brand-compliant application development. This repository uses **Google Anti-Gravity** to orchestrate app building while maintaining a strictly controlled "Living Shell" to protect our brand identity and accessibility (A11y) standards.



## 🏗️ Project Architecture

To keep the brand intact, we use a "Core vs. Active" directory structure:

* **`/core-template`**: **(READ-ONLY)** Contains the master `shell.html` and `brand-styles.css`. This is the DNA of our UI.
* **`.agent/rules/`**: Contains the `brand-guardrails.md` which instructs Anti-Gravity on where it can and cannot write code.
* **`index.html`**: The active file at the root. Anti-Gravity will inject app logic into this file's `#ag-app-canvas`.
* **`/src`**: The workspace for supplemental JavaScript and logic generated by the agent.

## 🚦 The Rules of the Road

When you open this project in Anti-Gravity, the agent is automatically governed by the following constraints:

1.  **The Sandbox**: All UI generation is restricted to `<div id="ag-app-canvas">`.
2.  **No Inline Styles**: The agent is forbidden from using the `style` attribute. It must use the utility classes found in `core-template/brand-styles.css`.
3.  **A11y First**: Every generated element must be keyboard-navigable and include proper `aria-` attributes.
4.  **Shell Integrity**: The Header, Footer, and Navigation are immutable.
